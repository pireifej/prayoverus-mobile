The EAS build is still failing because Expo SDK locks the root Kotlin compiler to version 2.1.20, but the Google Mobile Ads SDK is dynamically pulling in `play-services-ads:25.4.0` (which requires Kotlin 2.3.0).

We need to force Gradle to use `play-services-ads:23.6.0` across the project so it stays compatible with Expo's Kotlin compiler.

Please perform the following steps:

1. Check if an `android/` directory exists in the workspace.
   - If `android/` exists, open `android/build.gradle` and add this block to the bottom of the file:
     ```groovy
     allprojects {
         configurations.all {
             resolutionStrategy {
                 force 'com.google.android.gms:play-services-ads:23.6.0'
             }
         }
     }
     ```

2. If using Managed Expo Prebuild (no `android/` committed folder), create a local Expo Config Plugin to inject the resolution strategy during prebuild:
   - Create a file named `withForceAdmobVersion.js` in the project root:
     ```javascript
     const { withProjectBuildGradle } = require('@expo/config-plugins');

     module.exports = function withForceAdmobVersion(config) {
       return withProjectBuildGradle(config, (config) => {
         if (config.modResults.language === 'groovy') {
           config.modResults.contents += `\n
     allprojects {
         configurations.all {
             resolutionStrategy {
                 force 'com.google.android.gms:play-services-ads:23.6.0'
             }
         }
     }
     `;
         }
         return config;
       });
     };
     ```
   - In `app.json`, register this plugin in `"plugins"`:
     ```json
     "plugins": [
       "./withForceAdmobVersion",
       [
         "react-native-google-mobile-ads",
         {
           "androidAppId": "ca-app-pub-3940256099942544~3347511713"
         }
       ]
     ]
     ```

3. If an `android/` directory exists in Git/workspace, delete it (`rm -rf android`) so Expo prebuild generates fresh native files with the new config plugin, or commit the `android/build.gradle` change directly.
